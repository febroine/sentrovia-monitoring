# Sentrovia v0.5.0

## Changes

- Simplify onboarding and sign-in, operational dashboards, settings, member and company management.
- Use consistent action colors, compact monitoring summaries, clearer empty states, and readable tables with horizontal scrolling.
- Add reliability analytics, daily report metrics and clearer report previews; simplify downloadable HTML reports.
- Add temporary monitor pauses and improve text/CSV imports and workspace notification defaults.
- Remove the legacy incident coordination and maintenance-window features.

## Upgrade notes

Back up the database before upgrading. The normal schema-sync process applies migrations 0083 through 0085. Migration 0084 removes incident_updates and maintenance_windows tables and retired incident assignment, acknowledgement and escalation columns. Their stored data is not retained by the migration. Monitor outage history remains.

## Validation

Local validation completed before release preparation: production build, typecheck, UI lint, 110 targeted tests and focused report-export tests. Desktop/mobile checks included a separate 25-monitor fixture for pagination, filtering, selection and long content. External notification sends were not performed. The release workflow additionally runs the repository CI checks and publishes the source archive, checksums, attestation and Docker image.
